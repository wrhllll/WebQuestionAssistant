# 网页题目助手

网页题目助手是适用于 **Google Chrome、Microsoft Edge 等 Chromium 内核浏览器**的 Manifest V3 扩展，可将网页长页面截取为整页图片，并把题目整理成独立截图。你可以选择本地自动框选并导出，也可以使用视觉 AI 定位题目、逐题解答。

## 功能介绍

- **整页截图**：滚动采集当前标签页并拼接成长图，显示采集进度；采集结束后打开结果页（或在开启自动下载时直接导出）。关闭弹窗可尝试取消采集，扩展会尝试恢复原滚动位置。
- **两种工作模式**：
  - **本地自动框选**：根据页面中可见的题目结构和题号识别题目区域，并尝试避开答题输入区。检测和裁切在本机完成，不调用 API；可将选中的题目导出为合并 PNG 或 A4 PDF，也可在设置页开启“截完直接自动下载”并多选默认下载格式。网页结构不适合自动识别时，可手动框选或改用 AI 视觉识别。
  - **AI 视觉识别与解答**：视觉模型识别整页截图中的题目位置。检查并确认题目后，扩展会按题号顺序逐张发送选中的题目截图并请求解答；整页截图不会随逐题解答请求重复发送。可取消后续请求或重试失败题目。
- **题目整理**：结果页左侧目录可跳转至对应题目。题目默认折叠，可展开查看；识别结果可增删、编辑题号、取消选择，并在整页截图上移动或调整裁切框。删除前会二次确认，删除后自动重排编号。
- **后续框选**：解答完成后可重新框选某道题并自动重新解答，也可继续框选新增题目并解答。
- **本地导出**：选定题目后可导出合并 PNG 或 A4 PDF，无需将图片发送给 API。
- **多套 API 配置**：保存并切换多套视觉模型配置，可使用服务商预设或填写兼容 OpenAI Chat Completions 图像消息格式的自定义 API。
- **双弹窗风格**：设置页支持一键切换“极简原版”（默认，仅保留主按钮与设置）与“详细版”（弹窗内快捷切换模式、多选下载格式、查看当前 API 与填写补充说明）。
- **答案排版**：支持 Markdown、常见 LaTeX 公式、SSE 流式输出与 DeepSeek 风格折叠思考链显示。
- **更新提醒**：后台每 12 小时静默检查 GitHub Releases，发现新版本时在扩展图标上显示 `NEW` 角标，并在设置页提供一键下载入口。

## 使用方法

### 安装扩展（Chrome / Edge 等 Chromium 浏览器）

1. 下载并解压 `web-question-assistant.zip`（或 Releases 页面提供的 ZIP 文件）。
2. 在浏览器地址栏打开 `chrome://extensions`（Chrome）或 `edge://extensions`（Edge），启用右上角“开发者模式”/“开发人员模式”。
3. 点击“加载已解压的扩展程序”/“加载解压缩的扩展”，并指定包含 `manifest.json` 的文件夹。
4. 点击浏览器工具栏上的“网页题目助手”图标。

### 选择工作模式

1. 在扩展弹窗点击“设置”。
2. 选择默认工作模式：
   - 选择“本地自动框选并导出”时，截图后会在本机检测题目，不会自动调用 API；可按需勾选“不进入预览与微调页（截完直接自动下载）”并多选默认下载格式（合并 PNG / A4 PDF）。
   - 选择“AI 视觉识别并逐题解答”时，截图后会打开结果页并开始视觉识别。
3. 使用 AI 模式前，在设置页新增或选择一套 API 配置，填写模型名称和 API Key，然后保存并启用。模型必须支持图像输入，API 需要兼容 Chat Completions 的图像消息格式。
4. 首次访问 API 域名时，浏览器会请求该域名的访问权限。API 地址需使用 HTTPS；只有本机 `localhost` 可使用 HTTP。

### 截图、检查与处理题目

1. 在要处理的网页中点击扩展图标，再点击“截取网页长图”。截图完成后会自动打开结果标签页（若在本地模式下开启了自动下载，则直接下载所选格式文件）。
2. 根据默认工作模式检查题目：
   - 本地模式会显示自动框选结果；如未识别到题目，可在整页截图上手动框选，或点击“重新识别”使用 AI。
   - AI 模式会将整页截图发送给所选视觉 API 以识别题目位置。模型可能漏识别或误判，请在确认前检查结果。
3. 点击目录项跳转题目；展开题目查看截图。可拖动题目框移动位置，拖动边缘或角点调整大小；也可修改题号、取消勾选或删除题目。新增题目时，在整页截图空白处按住并拖动完成框选。
4. 本地模式下，选择需要的题目后点击“导出合并 PNG”或“导出 A4 PDF”。
5. 需要 AI 解答时，点击“确认并逐题求解”。题目会按题号逐张提交，解答显示在对应题目下方。解答完成后，可重新框选题目或点击“新增题目”继续处理。

## 数据与使用限制

API Key 和截图记录保存在扩展本机存储中；最近的 5 份截图记录会保留。使用本地模式进行检测和导出时，页面截图不会发送给 API。AI 识别会发送整页截图；AI 解答只会发送用户确认的单题裁切图。请勿对包含不希望发送给所选服务的内容使用 AI 模式。

本地自动检测依赖网页的可见文字和结构，不保证适用于所有网站；可改用手动框选或 AI 识别。浏览器内部页面（如 `chrome://`、`edge://`）、扩展商店等受限页面可能不允许截图或页面操作；嵌套滚动区域、跨源嵌入内容和动态页面也可能无法完整采集。AI 生成的答案仅供参考，请自行核对。
